## 一、阶段结论

已经完成并发布一份真正的**单文件项目网站**。项目机制、研究证据、Flower、企业服务、合作路线、治理与问答均在同一份 HTML 的正文中，目录只跳转本页章节。

此前“五个菜单切换独立页面”的 iframe 门户已被替换。现在的发布产物只有 `index.html`，不需要再加载其他页面、样式、脚本、字体、图片或 JSON 才能阅读项目。

网站地址：**[https://fishman-free.github.io/REDTEAM/](https://fishman-free.github.io/REDTEAM/)**。

> 网站是已上线的研究介绍；网站上线不代表实验靶场已向公众开放、企业平台已交付，或 Flower 已在公网链发行。

## 二、已完成的内容

### 2.1 将各方面内容整合到同一正文

| 章节 | 页面中已有的实质内容 |
|---|---|
| 项目概览 | 智能体交易安全问题、研究定位、授权与模拟边界。 |
| 攻防机制 | 虚拟社区三角色、验收后付款例子、三环流程、L0/L1、四输入面、七工具。 |
| 研究证据 | 日期与版本明确的真实模型结果、未解决发现、修复限制、历史统计校正及六字段样本。 |
| Flower | 人工审核、接收同意、不可转让、撤销、隐私和同一 token 的两个本地快照。 |
| 企业服务 | 候选客户、六项 MVP、交付包、收入及成本假设。 |
| 路线图 | 90 天建议、合作角色及场景、算力、研究与治理资源诉求。 |
| 治理 | 五类风险、资金与数据边界、停线条件。 |
| 问答 | 16 项合并去重的问答。 |
| 资料 | 当前与历史文档的用途、替代关系和复核链接。 |

旧概览、Flower 页和两份历史介绍仍在仓库中作为来源保存，但不再作为新网站的运行依赖。重复说明合并；历史稿中独有的商业、合作与治理内容进入对应章节，不能用一串外链代替正文。

### 2.2 视觉与交互

参考用户指定的 [支付宝 PAYATHON 页面](https://aipay.alipay.com/community/events/payathon-2026?product=AI_WEB_APP_PAY&accessMode=agent) 的设计语言，采用：

- 深炭黑底色、暖珊瑚色点缀、明亮文字与灰色辅助信息；
- 大标题、宽留白、长页面的分章节叙事；
- 原创授权边界轨道 SVG，而非支付宝品牌图形或赛事资产；
- 横向粘性导航、移动端菜单和本页锚点定位；
- 同一文档内的 L0/L1 与路线阶段切换；
- 问答展开、装饰动效暂停、减少动效偏好与打印状态恢复。

不复制赛事报名、奖金、合作伙伴或机构背书，也不宣称 REDTEAM 与支付宝存在合作关系。

### 2.3 单文件和离线阅读

CSS、必要 JavaScript、SVG、小花 JSON 与实际图形全部内联。关闭 JavaScript 后，正文、协议与路线阶段、两幅实际小花仍可阅读；脚本仅增强交互与数据核验，不承担正文加载。

Flower 展示的是本地 Hardhat 31337 上**同一枚 token #1 的发行后与撤销后快照**，不是两枚 NFT，也不是实时公网链查询。没有连接钱包、导入私钥、铸造或交易入口。

## 三、实现与发布方式

| 文件 | 职责 |
|---|---|
| [网页编辑源](../site/index.html) | 完整单页，样式、交互和演示数据均内联。 |

| [站点 CI](../../.github/workflows/site.yml) | 在 Windows 与 Linux 检查单文件与内容。 |

现有 GitHub Pages 从 `main` 根目录发布。构建产物只有一个 HTML，原始研究材料不作为网站页面公开。技术资料仍可通过 GitHub 查看。

维护命令：

```bash
python scripts/build_site.py
python scripts/build_site.py --check
python -m unittest discover -s tests -p test_site_build.py -v
```

## 五、尚未完成或不在本阶段范围内

1. **生产业务界面。** 没有企业项目管理、客户登录、多租户控制或真实支付接入。
2. **公开 NFT 操作界面。** 没有领取、钱包连接、交易或主网发行；是否需要这些能力必须另行审查。
3. **全面辅助技术和真人审美验收。** 当前有键盘、焦点、减少动效和浏览器检查，但不能称已完成所有屏幕阅读器与设备组合测试。
4. **长期内容运营与监测。** 实验报告、进度、引用和文档需要持续维护；没有经验证的网站使用或转化数据。
5. **About 网站入口。** 核验时仓库 Website 仍为空；当前账号缺少管理权限，已选择由 Owner 手动填写。这不是前端部署失败，也不能写成已设置成功。
