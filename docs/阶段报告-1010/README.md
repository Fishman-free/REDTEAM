## 四、统一阅读边界

1. **测试通过不等于生产安全。** 局部源码测试、模型实验、浏览器验证、安全审计与法律判断是不同证据。
2. **网站上线不等于 NFT 发行。** 页面只展示合成的本地历史快照，不连接钱包或运行发行服务。
3. **NFT 锁定不等于法律豁免。** 钱包控制、公开地址关联、不可删除历史、贡献审核与发行者权限仍需治理。
4. **商业方案不等于业务已运营。** 候选客户、人民币收费、合同、开票纳税与试点均须由实际记录验证。
5. **历史代码不改写身份。** RTM 仍是可转让 ERC-20 研究；BountyRound 没有完整 reveal 验证；局部桥接不等于公众自动领奖平台。
