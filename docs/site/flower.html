01

一朵花，经过三道确认。

不能因为链上存在一个 token，就说贡献是真的。判断在链下完成；合约只约束发行权限、贡献标识、接收同意与不可转让状态。

  1. 发行者审核贡献

    可信审核者核对授权、证据、复现、去重与披露权限。model finding 指模型层确认违规，不是基础模型训练改善。digest 仅绑定材料字节，不证明事实真实。

  2. 接收者明确同意

    接收 EOA 用 EIP-712 签名确认绑定内容、nonce 与期限，然后由发行者免费发行。普通钱包控制只证明密钥控制，不是真实身份认证；不支持代理接收。

  3. 锁定，仍可撤销认可

    转让与转让授权被禁用。撤销只标记认可状态，保留原 token、原 owner 与历史；不焚毁换人，也没有管理员换钱包或重新分配接口。

免费的是合约发行价格，不是未来公共链 gas 免费的承诺。锁定 token 也不能阻止钱包或私钥本身被转卖、泄漏或被胁迫控制。

03

把边界说清楚，才是认真认可。

技术限制不会自动带来法律豁免。任何真实公开发行或商业接入都需要独立审查，而不是从本地 demo 直接上线。

PRIVACY

不把公开链当私密档案

展示元数据不含钱包与证据摘要，但 ERC-721 owner 与事件仍可公开接收地址和 contributionId。hash 不等于匿名，撤销不删除历史。原始证据不公开；当前只使用合成材料。

REVIEW

审查不能由名字代替

“NFT”“免费”“不可转让”都不保证合法。公开发行待法律、隐私、安全与人工审核流程审查；未来贡献键需研究加盐假名化与最小化。专业人士的口头建议不是监管批准或正式法律意见。

RESEARCH

不为生产安全背书

Flower 不证明模型已改善或应用可上线。PayAssist 已有 2026-10-05 live.v3/v5 真实模型实验，但仍有 12 个开放发现；有限冻结验收通过不是生产安全证书。

商业主线，仍是可复核的安全服务。

企业安全评测、整改复核与持续回归服务独立于 Flower；不依赖 NFT 售卖或持有资格。当前商业计划以 Flower 功能分支的 Markdown 讨论稿为准（尚未合并到 main，GitHub 上的讨论稿可能仍为旧版）；现存 PDF 是本次更新前旧快照，未重新生成，产品说明已被当前 Markdown 替代。原法律引文未独立核验。

04

关于这朵花，还需要知道。

这是真正的 NFT，还是改名后的积分？
是 ERC-721 + ERC-5192 的本地不可转让 NFT 合约原型，不是历史 RTM ERC-20 的改名。NFT 描述的是技术结构，不保证合法、稀缺价值或财产权利。
撤销后，能把同一枚转给另一位贡献者吗？
不能。撤销保留原 token 与原 owner，只改变认可状态。无管理员重分配、代理接收或遗失钱包迁移捷径；快照中的两张卡是同一 token 的前后时点。
它能证明贡献者的真实身份，或贡献确实成立吗？
不能。普通 EOA 签名只证明密钥控制，审核声明来自可信链下控制者，不是身份认证或事实 oracle。digest 只核验字节一致；贡献事实、授权和披露权限仍须人工审核。
可以公开发行或接入企业服务了吗？
没有这样的结论。当前仅无分叉 Hardhat 31337 与合成材料；法律、隐私、安全、发行者权限、接收同意和撤销治理均需进一步专业审查。主网、市场、真实身份系统和商业权益不属于本次原型。
