## 3. 两层机制（不要混）

| 维度 | 用户攻防层（保持原设计） | 平台挖矿层（本次重构） |
|---|---|---|
| 守方 | 用户自带智能体 | 平台自有智能体 |
| 攻方 | 普通攻方，质押 `s=r·S` | 矿工，**无质押** |
| 奖池 | 守方质押 S | Treasury 预置 **1 RTM** |
| 发行 | 无增发 | **每次成功攻破 +1 RTM** |
| 罚款 | 25%/2h，归守方 | **无罚款/无剩余质押提款** |
| 消息费 | 0.5%×S | **0.005 RTM/条**（1 RTM × 0.5%） |
| 数据 | join 时 opt-in，可售 | **强制留存，仅 RSI，不售** |
| 经济 | 零和 + 手续费/推理费 | 事件驱动增发，非零和 |
| 生命周期 | 到期/攻破/弃权 | 攻破或平台退役，立即停赛 |

**用户层关键参数不变**：S 默认 50、r 2%–20% 默认 10%、D 6h–7d、罚款 25%/2h、每场最多 50 攻方、加入后不可退出、靶钱包策略、到期/攻破/弃权结算、排行榜、数据市场 70/30 都保留。

## 4. 挖矿层最终契约（R2 要落地）

### 常量
- `MINING_REWARD = 1e18`（1 RTM）
- `FEE_BPS = 50`（普通与挖矿共用 0.5%；挖矿基数 = 1 RTM）
- `MAX_ACTIVE_MINING = 3`
- 删除 `accrue`、`E_rate`、`miningRate`、`miningMinted`、`MAX_MINING_RATE`。

### 创建/加入/退役
- `createMiningContest(address wallet, bytes32 defenseHash)` onlyOperator：
  - `defenseHash != 0`；未 retired；无 active 同 hash；活跃数 <3。
  - wallet 必须新、非靶、未受控、余额为 0（保证固定 1 RTM 起点）。
  - 从 Treasury `transferFrom` **1 RTM** 到 W；Treasury 需预注资并 `approveSpender(rtm, arena, ...)`。
  - 注册 W 为靶；记录 `isMining=true, defenseHash`；无 stakeBps/rate。
- `joinMining(bytes32 id, bool acceptData)`：
  - `acceptData` 必须 true，否则 `DataConsentRequired`。
  - 每地址一次、最多 50 人；无质押、无罚款、无 `withdrawStake`、无 `collectPenalties`。
  - `stake=0`、`base=1 RTM`（用于 0.005 费用）、`dataConsent=true`；发 `MiningJoined`/数据同意事件。
- `join(bytes32 id, uint256 maxStake, bool dataConsent)`：普通赛；记录 `dataConsent`。
- `retireMining(bytes32 id)` onlyOperator（R1 文档新增；R2 实现或同步改文档）：
  - 仅 Live、`isMining`；结束比赛；W 余额（正常 1 RTM）退回 Treasury；**不铸造**；hash retired。
- `dataConsent(bytes32 id, address attacker) external view returns (bool)`。
- `retiredDefenseHash(bytes32) public`、`activeDefenseHash(bytes32) public`（或等价命名）。

### 攻破
- 矿工诱导 W 把 1 RTM 转给自己 → RTMToken 触发 `onBreach`。
- W 的 1 RTM 归获胜矿工（Token 的 `onBreach` 扫走剩余；合计 1 RTM）。
- Arena `onBreach`：结束本场；`defenseHash` retired；向 Treasury **铸造 1 RTM**（补偿预置奖池）；runner 停服 → RSI → 新版本/新 hash。
- 净增发 = **1 RTM/成功攻破**；未攻破不增发。
- 未攻破退役/fault：W 的 1 RTM 回 Treasury，不铸造；hash retired。

### 重要风险
- 平台若自己控制矿工攻击自己的挖矿赛，奖励是净增发 1 RTM（手续费内部转移），**不再是“平台自攻净零”**；缓解：不自我挖矿、审计、K=3、hash 退役。链上无法完全禁止。
- 普通层“自攻自守严格亏损”仍然成立，不要与挖矿层混淆。

## 5. 数据同意（R2 + R3）

### 普通攻方
- join 时一次性 `dataConsent`；不可撤回。
- true：平台可持久化消息/回复/工具轨迹/snapshot；赛后守方可选择购买；平台 70% / 攻方 30%。
- false：不落盘、不进入数据集、不可售；runner 只在内存处理，不写日志/证据。
- DataMarket 删除 `approveSale`/`saleApproved`/`SaleApproved`/`NotApproved`；`buyFromAttacker` 读 `Arena.dataConsent`，未同意 revert `NotConsented`。
- `publish` 只允许普通赛；`buyOwn`/`buyFromAttacker` 仍仅 defender、赛后、70/30、一次性。
- 数据集根只含同意攻方数据 + 守方自有数据；平台后端负责排除 opt-out。

### 矿工
- `joinMining` 强制 `acceptData=true`；UI/条款在加入前明示。
- 平台无条件持久化全部矿工数据，仅用于 RSI；**不进入 DataMarket、不出售**。
- 矿工不需要质押，数据本身就是参与对价的一部分。
